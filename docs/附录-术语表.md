# 附录 · 量化术语表（人话版）

> 按学习路线大致排序，不按字母序——新手从前往后读，老手当词典查。
> 绩效六兄弟（收益率/回撤/夏普等）的"及格线"速查在 [第 2 章 2.6 节](02-量化核心概念.md)，
> 本表只负责"它是什么"。遇到报错请转 [第 13 章 FAQ](13-常见问题FAQ与进阶路线.md)。

| 术语 | 人话解释 |
|------|---------|
| K线 / OHLCV | 一段时间的价格四件套：开、高、低、收，外加成交量 V。日线的每根 K 线 = 一天 |
| ETF | 交易所交易的基金，如 510300（沪深300ETF）。像股票一样买卖，免印花税，新手首选 |
| 前复权（qfq） | 把历史价格按分红除权"平移"到和今天可比。不复权的历史 K 线有假跳空，回测信号全是错的 |
| 均线（MA） | 最近 N 天收盘价的平均值连成的线。MA20 = 20 日均线，用来滤掉日常噪音看趋势 |
| 金叉 / 死叉 | 短期均线上穿长期均线（金叉，看涨信号）/ 下穿（死叉，看跌信号） |
| 择时 | 决定"什么时候该持有、什么时候该空仓"，不挑股票只挑时间。双均线是最简单的择时 |
| 信号 / 目标仓位 | 策略每根 K 线输出的数字：0=空仓，1=满仓，0.3=三成仓。引擎照着它调仓 |
| 未来函数（前视偏差） | 回测时偷用了"当时还不可能知道"的信息（比如用今天收盘价算今天的信号），回测虚高、实盘现形 |
| next_open | 本项目引擎的默认成交规则：今天收盘算出信号，明天开盘才成交——从机制上杜绝未来函数 |
| 佣金 | 券商/交易所每笔交易收的手续费，按成交金额比例算。A股 ETF 约万 1~万 3，币安现货约千 1 |
| 最低佣金（min_fee） | 券商"每笔最少收 5 元"的规则。小资金频繁交易会被它吃掉利润，引擎会对碎单跳过保护 |
| 滑点 | 你看到的价格和实际成交价的差。买入常成交在略高处、卖出在略低处，流动性越差滑点越大 |
| 印花税 | A股个股卖出时国家收的税（2023-09 起万分之五），只扣卖出腿；ETF 和加密货币免收 |
| 净值曲线（equity） | 账户总资产（现金+持仓市值）随时间的变化线，回测的最终产出 |
| 基准 / 买入持有 | 什么都不干、一开始就买死拿着的收益。你的策略跑不赢它，说明择时在帮倒忙 |
| 总收益率 | 期末 ÷ 期初 − 1。最容易骗人的指标：+50% 之前可能先 −60% 过一轮 |
| 年化收益率（CAGR） | 把几年的总收益折算成"复利每年多少"。跨周期比较策略必须用它，不能直接比总收益 |
| 年化波动率 | 收益率的标准差折算到一年，衡量"坐过山车的剧烈程度" |
| 最大回撤（MDD） | 净值从历史最高点跌到之后最低点的最大幅度。衡量"最难熬时亏多少"——决定你拿不拿得住 |
| 夏普比率 | 每承担 1 单位波动换来多少超额收益。<0 危险，>1 良好，>2 优秀 |
| 索提诺比率 | 夏普的改良版：只惩罚下跌波动，上涨的"波动"不扣分 |
| 卡玛比率 | 年化收益 ÷ 最大回撤。"每受过 1 单位伤换多少收益"，回撤大的策略它最打脸 |
| 胜率 | 赚钱的交易占全部交易的比例。趋势策略 30~40% 是常态，必须和盈亏比绑着看 |
| 盈亏比 | 平均每笔赚的钱 ÷ 平均每笔亏的钱。胜率 35% × 盈亏比 3:1 照样赚钱 |
| 换仓次数 | 信号翻转（0→1 或 1→0）的次数。翻得越勤佣金滑点磨损越大 |
| 过拟合 | 参数调到回测里完美、实盘就崩——策略"背题"背的是历史噪音，不是规律 |
| 参数扫描 | 把快慢均线等参数组合全跑一遍看结果分布。结果对参数越敏感，越可能是过拟合 |
| 样本内 / 样本外 | 调参数用的数据段是样本内；留出来没参与调参的段是样本外。只有样本外能说明真实水平 |
| Walk-Forward（前推验证） | 滚动地"用过去调参→在紧接着的未来验证"，重复多次。比一次性切分更接近真实使用 |
| 止损 | 亏损到预设线就认错卖出（本项目：盘中最低价触发、次日开盘执行）。先认错，再谈别的 |
| ATR | 平均真实波幅，一段行情"一天通常走多大"的度量。用来按波动率定止损宽度和仓位大小 |
| 仓位 / 权重 | 押了多大比例的资金。仓位管理回答"买多少"——它比"买什么"更决定生死 |
| T+1 | A股今天买明天才能卖。回测引擎默认次日开盘成交，天然符合 T+1 |
| 模拟盘 / 测试网（testnet） | 交易所/平台提供的仿真环境：真实行情、假资金。上真钱前必须先在这里空转验证 |
| dry-run | "干跑"模式：代码完整执行但只打印不下单。本项目币安机器人的第一档保险 |
| API Key | 交易所发给你的编程接口密钥。只放 .env，绝不写进代码/截图/聊天记录；只开"交易"权限、禁提币 |
| ccxt | 统一接口封装上百家交易所的开源库。学会一套 API，币安/OKX/Bybit 通吃 |
| .env | 项目根目录的配置文件，存密钥和参数。被 .gitignore 排除，永远不会提交到仓库 |
| 限流 | 免费数据接口对高频请求临时断连/拒绝。等几分钟再试，或用本地缓存、样例数据兜底 |
| 离线兜底 | 网络失败时的 Plan B：A股自动回退 data/*.csv 缓存；`--csv` 可指定任意本地数据离线回测 |
