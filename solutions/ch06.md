## 题 1：换策略回测（动量 vs 双均线）
```python
from ch03_data.datasource import fetch_daily_with_cache
from ch04_backtest.engine import run_backtest
from ch05_metrics.performance import print_stats
from research.signals import momentum_weights
from ch04_backtest.strategy import dual_ma_weights

df = fetch_daily_with_cache("510300")
r1 = run_backtest(df, momentum_weights(df, lookback=20), with_benchmark=False)
r2 = run_backtest(df, dual_ma_weights(df, 20, 60), with_benchmark=False)
print("动量策略:"); print_stats(r1.stats)
print("双均线:  "); print_stats(r2.stats)
```
**预期**：两者都是趋势策略，结果方向相近（哪个更好取决于 lookback 和行情段）。重点是**学会"换策略 = 换一个返回 0~1 权重的函数"**，引擎完全不用动。

## 题 2：写一个可证伪的假设
按四要素模板，示例：
> "标的=510300；当 RSI(14) < 30（超卖）时买入；当 RSI 回到 50 以上时卖出；预期比一直持有回撤更小。"

判断它可证伪：因为"RSI<30 买入"是明确规则，任何人照着做结果一致，且**可能被数据推翻**（如果回测显示它更差，假设就被证伪了）。

## 题 3：实现假设（RSI 均值回归）
```python
from research.signals import rsi_factor, factor_to_weights
from ch03_data.datasource import fetch_daily_with_cache
from ch04_backtest.engine import run_backtest

df = fetch_daily_with_cache("510300")
rsi = rsi_factor(df, period=14)
w = factor_to_weights(rsi, upper=50, lower=30)   # RSI>50 卖(0)、RSI<=30 买(1)? 
```
> 注意方向：均值回归是"超卖(低RSI)买入、回到中位卖出"。所以应该是 `factor_to_weights(rsi, upper=50)` 的**反向**：低 RSI 给 1、高 RSI 给 0。最直接的是自己写：
```python
w = (rsi < 30).astype(float)      # 超卖=1(买入)，其余=0
w[(rsi > 50)] = 0.0               # 回到 50 上方卖出
w[rsi.isna()] = float("nan")      # 数据不足维持现状
```
跑回测，很可能结果不理想——**这很正常**，均值回归在单边市场会持续亏损，第 6.5 的分组检验会告诉你这个因子到底有没有效。

## 题 4：检验"超卖反弹"
```python
import pandas as pd
from ch03_data.datasource import fetch_daily_with_cache
from research.signals import rsi_factor

df = fetch_daily_with_cache("510300")
rsi = rsi_factor(df, period=14)
fwd = df["close"].pct_change(20).shift(-20)   # 未来20天收益
q = pd.qcut(rsi, 3, labels=["低", "中", "高"])
print(fwd.groupby(q).mean())
```
**解读**：若"低"组的未来 20 天平均收益 > "高"组，说明"超卖会反弹"有数据支持；若三组差不多或反过来，说明这个因子在当前标的/时段无效。**只看平均不够，还要看稳定性**（分年度看是否年年成立）。

## 题 5：唐奇安突破 vs 双均线
```python
from research.signals import donchian_breakout_weights
from ch03_data.datasource import fetch_daily_with_cache
from ch04_backtest.engine import run_backtest

df = fetch_daily_with_cache("510300")
r = run_backtest(df, donchian_breakout_weights(df, entry=20, exit_=10), with_benchmark=False)
print(r.stats)
```
唐奇安是"突破型"趋势策略，和均线交叉是两套信号逻辑。对比它们的**回撤曲线形状**：突破型往往在趋势启动时更早进场，但在假突破时止损更快。感受"不同信号逻辑 → 不同风险画像"。
