打开 `dual_ma_510300_trades.csv`，看 `side` 列：一次 SELL 结束一笔交易。把每笔 round-trip 的盈亏串起来，找"连续亏损"最长的一段。

## 题 4：单均线版本
```python
import pandas as pd
def price_above_ma_weights(df, n=60):
    ma = df["close"].rolling(n).mean()
    w = pd.Series(float("nan"), index=df.index)
    w[(df["close"] > ma) & ma.notna()] = 1.0
    w[(df["close"] <= ma) & ma.notna()] = 0.0
    return w
```
跑一遍对比双均线。**大概率结果更差或差不多**——因为单均线对短期波动的过滤更弱，震荡市进出更频繁、成本更高。这验证了"参数和结构的选择都有代价"，也引出第 7 章的过拟合话题。
