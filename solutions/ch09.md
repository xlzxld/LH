## 题 4：每日心跳
`live_bot.py` 其实**已经内置了每日心跳**（`maybe_heartbeat`，每天第一条日志后发一次）。本题的意义是理解它的实现思路：
```python
from datetime import date
today = date.today().isoformat()
if state.get("last_heartbeat") != today:
    state["last_heartbeat"] = today
    save_state(STATE_FILE, state)
    send_text("💓 心跳", f"今天还活着，模式: {mode}")
```
**核心是"判断日期是否变化"**：日期变了才发，避免每轮轮询都发一条刷屏。你可以在 `maybe_heartbeat` 的 body 里补上"当日盈亏"（需要记录期初余额，进阶）。
