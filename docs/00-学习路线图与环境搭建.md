## 0.2 安装 Python 环境

### 你需要装的软件（按顺序）

1. **Python 3.10 或更新**：去 [python.org/downloads](https://www.python.org/downloads/) 下载。
   ⚠️ Windows 安装时**必须勾选 "Add Python to PATH"**（第一个安装界面的底部复选框），否则命令行找不到 python。
   验证：打开终端（Windows 按 Win+R 输入 `powershell`，Mac 打开"终端"）输入：

   ```bash
   python --version     # 显示 Python 3.10+ 即可（本项目在 3.14 上开发验证）
   ```

2. **VS Code（推荐）**：[code.visualstudio.com](https://code.visualstudio.com/)，装好后扩展商店里搜索安装 **Python**（微软官方）扩展。用它打开本项目的"量化"文件夹。

### 虚拟环境：为什么要 + 怎么建

**为什么**：不同项目依赖不同版本的库，直接往系统 Python 里装会互相打架。虚拟环境 = 给本项目一个独立的"库仓库"，删掉不影响系统。

**怎么做**（在项目目录"量化"里打开终端）：

```bash
# 创建（只需一次）
python -m venv .venv

# 激活（每开一个新终端都要做）
# Windows PowerShell:
.venv\Scripts\Activate.ps1
# Windows Git Bash:
source .venv/Scripts/activate
# Mac/Linux:
source .venv/bin/activate

# 激活成功后，命令行前面会出现 (.venv) 字样
```

> PowerShell 提示"禁止运行脚本"？以管理员打开 PowerShell 执行一次：
> `Set-ExecutionPolicy -ExecutionPolicy RemoteSigned -Scope CurrentUser`

### 安装依赖

```bash
pip install -r requirements.txt
```

国内下载慢？用清华镜像（把这条记到备忘录，以后所有 pip install 都可以加）：

```bash
pip install -r requirements.txt -i https://pypi.tuna.tsinghua.edu.cn/simple
```

### 配置文件

```bash
# Windows
copy .env.example .env
# Mac/Linux
cp .env.example .env
```

`.env` 是整个项目**唯一的**配置文件：推送密钥、交易所 API Key 都放这里。
现在什么都不用填 —— 前 6 章不需要任何密钥。`.env` 已列入 `.gitignore`，
**永远不要**把它发给别人或传到 GitHub。

### 自检

```bash
python scripts/setup_check.py
```

逐项看输出：✅ 正常；❌ 必须处理（缺库就 pip install，网络不通看对应章节的说明）。

## 0.5 常见的坑（第 0 章）

| 症状 | 原因与解法 |
|------|-----------|
| `python` 不是内部或外部命令 | 安装时没勾 Add to PATH；重装勾上，或用 `py` 代替 `python` |
| PowerShell 无法激活 venv | 见上面的 ExecutionPolicy 命令 |
| pip 下载超时 | 用清华镜像参数 |
| 东财数据偶发"连续 3 次失败" | 免费接口限流，等 1~5 分钟再试；已下载过的标的会自动用本地缓存（`data/*.csv`） |
| 图里中文显示成方块 | Windows 一般正常；macOS/Linux 需中文字体（脚本已内置 PingFang/Noto，仍乱就装字体） |
| 终端输出 emoji 变 `?` 或报 UnicodeEncodeError | Windows 老控制台是 GBK 编码；用 Windows Terminal/VS Code 终端，或先执行 `set PYTHONUTF8=1` 再跑 |
| 改了 .env 不生效 | 已开着的终端里同名环境变量会**覆盖** .env（比如早前 export 过的值）；开个新终端再跑 |
