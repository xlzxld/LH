# 第 7 章 参考答案

## 题 1：参数扫描，找孤岛 or 高原
```bash
python code/research/param_scan.py --astock 510300
```
看输出的热力图：最优参数四周是"一小片亮"还是"针尖一点亮"。真实数据里 `MA30x60` 往往是个孤峰（旁边参数明显变差），这就是过拟合的活教材。

## 题 2：样本外验证
```bash
python code/research/walkforward.py --astock 510300 --fast 20 --slow 60
```
**预期**：样本外（2024 之后）通常为负或接近 0，脚本会判 `❌ 样本外亏损...不能上实盘`。这**不是失败**——它诚实告诉你：双均线在 A 股宽基上没有稳健的超额，直接上实盘会亏。这正是教程要教的第一课。

## 题 3：换标的再验（512100）
```bash
python code/research/walkforward.py --astock 512100 --fast 20 --slow 60
```
如果 510300 上样本外为负、512100 上也负，说明"这组参数 + 这类市场"都不行；如果某个标的样本外为正，再深挖它为什么不同（趋势性/波动性）。**同一组参数跨标的都成立，才叫稳健**。

## 题 4：警惕测试（极端参数）
```bash
python code/research/walkforward.py --astock 510300 --fast 5 --slow 40
```
真实结果（截至 2026-09-04 的数据，你的数字可能不同）：
样本内 **-13.04%**（回撤 -33.5%、29 笔），样本外反而 **+5.26%**（13 笔），脚本判 `✅ 通过第一道关`。

这和很多人预期的"极短均线必然样本内漂亮、样本外崩盘"**方向相反**，本身就是本期的教训：
1. **"过拟合崩盘"不是必然剧情**——样本内外切到不同的行情段，哪段有利纯看运气，
   方向无法预言。谁跟你保证"样本内好、样本外差"的固定剧本，谁就是在讲故事。
2. **但这个参数依然不合格**：样本内 -13%、回撤 -33.5%，第一道筛选就该淘汰——
   没必要等一个侥幸的样本外来救它。
3. **判定只认规则不认故事**：次数够不够、样本外正不正、落差大不大（第 7.4 的三条）。
   手工叙事（"极短均线会过拟合"）可以当直觉，不能当结论。

## 题 5：自制策略的完整样本外验证
把 `walkforward.py` 里的 `dual_ma_weights` 换成你自己的函数（比如第 6 章的 RSI 均值回归）：
```python
# 修改 walkforward.py 顶部 import 和两处调用
from research.signals import mean_reversion_weights
# ...
r_in  = run_backtest(in_df,  mean_reversion_weights(in_df),  with_benchmark=False)
r_out = run_backtest(out_df, mean_reversion_weights(out_df), with_benchmark=False)
```
走一遍完整流程：样本内看方向 → 样本外定生死。**这是"上实盘前清单"的第 1 条硬门槛**。
