### 3.2.1 预备：HTTP、JSON、API 是什么（5 分钟扫盲）

这一章要开始"和服务器对话"了。三个词先扫盲：

- **API**（应用程序接口）：别人服务器开放给你的"函数"。你本地调 `fetch_eastmoney_daily("510300")`，它替你去东方财富的服务器要数据——就像打电话点外卖。
- **HTTP 请求**：你和服务器对话的"电话"。你在代码里发一个 URL 请求，服务器返回数据。URL 里 `?` 后面的 `secid=1.510300&klt=101` 叫**查询参数**，是"告诉服务器你要什么"的选项。
- **JSON**：服务器返回数据的格式，长得像 Python 的字典/列表嵌套。`{"data": {"klines": ["日期,开盘,...", ...]}}`——拿到后用 `resp.json()` 转成 Python 对象，再一层层取值。

一句话串起来：**代码发 HTTP 请求（带查询参数）→ 服务器返回 JSON → 你解析成 DataFrame**。
本章的 `datasource.py` 全是这个套路，看懂一次，以后任何数据接口都会接。

## 3.3 读懂东方财富接口（授人以渔）

`datasource.py` 里 `fetch_eastmoney_daily` 的核心就一个 URL：

```
https://push2his.eastmoney.com/api/qt/stock/kline/get
    ?secid=1.510300        ← 1=沪市 0=深市（_eastmoney_secid 负责换算）
    &klt=101               ← 101=日线（103=周线，5=5分钟线…）
    &fqt=1                 ← 1=前复权（第 2 章讲过为什么必须）
    &beg=20180101&end=20500101
```

返回 JSON 里的 `data.klines` 是字符串列表，每行
`"日期,开盘,收盘,最高,最低,成交量,成交额"`——`fetch_eastmoney_daily` 只做了
解析和类型转换。**看懂这一个接口，你以后能自己读懂 akshare 里 80% 的 A 股数据函数源码**（它们大多封装同样的东财/新浪端点）。

对应到代码，`fetch_eastmoney_daily` 的骨架就是下面这样（完整版多了重试和缓存，见 `datasource.py`）：

```python
import requests

url = "https://push2his.eastmoney.com/api/qt/stock/kline/get"
params = {"secid": "1.510300", "klt": 101, "fqt": 1,
          "beg": "20180101", "end": "20500101"}
resp = requests.get(url, params=params, timeout=15)   # 发 HTTP 请求（带查询参数）
data = resp.json()                                    # 解析 JSON
klines = data["data"]["klines"]                       # 逐层取值：data -> klines
rows = [line.split(",") for line in klines]           # 每行"日期,开盘,..."切成列表
df = pd.DataFrame(rows, columns=["date", "open", "close", "high", "low", "volume", "amount"])
df["date"] = pd.to_datetime(df["date"]); df = df.set_index("date").astype(float)
```

对照 3.2.1 的"三句话"：`requests.get(...)` 是发请求，`resp.json()` 是解析 JSON，
`data["data"]["klines"]` 是逐层取值，最后 `pd.DataFrame` 装进表格。**所有数据接口都是这四步。**

实时快照同理（`fetch_realtime_quotes`），盘中调用返回最新价/涨跌幅，收盘后返回收盘数据——第 10 章监测机器人靠它盘中盯价。

> 北交所（8/4 开头）、港美股不在本项目范围；需要时自行研究东财 secid 规则或改用 akshare。

## 3.5 ccxt：加密货币数据的统一语言

ccxt 的理念：把 100+ 交易所的 API 翻译成同一套函数名。

## 3.6 数据质量检查（老手的习惯）

拿到数据先问四个问题，`datasource` 返回的 DataFrame 直接这样查：

```python
assert df.index.is_monotonic_increasing   # 1. 时间升序？
assert not df.index.has_duplicates        # 2. 无重复日期？
assert (df["close"] > 0).all()            # 3. 价格全为正？
gap = df.index.to_series().diff().dt.days.max()   # 4. 最大间隔天数（节假日除外应≈1~4）
print(f"行数 {len(df)}，区间 {df.index[0].date()}~{df.index[-1].date()}，最大间隔 {gap} 天")
```

坏数据的常见来源：接口偶发返回空、复权因子错乱、退市股最后一段缺失。**垃圾进 = 垃圾出**，
回测结果诡异时先怀疑数据再怀疑策略。

## 3.7 CSV 缓存规范

- `save_csv` 用 `utf-8-sig` 编码——Excel 双击打开中文不乱码（普通 utf-8 会乱）。
- 缓存的意义：① 离线可跑回测；② 免费接口限流时不中断工作；③ 复现实验结果。
- 刷新缓存：删掉 `data/xxx.csv` 重新跑即可。实盘机器人的状态文件在 `data/state/`（第 9/10 章）。

## 常见的坑

- 直接 `requests.get` 东财不带 UA 会被拒；本项目已带。
- `df["close"]` 列是字符串？接口解析后务必 `astype(float)`（`datasource` 已处理，自己接新源时容易漏）。
- akshare 函数名升级很频繁，报 `AttributeError` 先 `print(dir(ak))` 找新名字。
- 时区：币安K线时间戳是 UTC，`pd.to_datetime(unit="ms")` 转完是 UTC 时间，北京时间要 +8（本项目画图按 UTC，日线级别无影响，细粒度策略要注意）。
