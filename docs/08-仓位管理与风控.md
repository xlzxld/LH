# 第 8 章 · 仓位管理与风控：决定你死不死的一章

> **学习目标**：回答"这一笔买多少、什么时候认错"两个决定生死的问题。
> **配套代码**：`code/ch06_risk/position_sizing.py`
> **耗时**：1 天 + 终身实践

## 8.1 为什么仓位比策略更重要

一个胜率 40%、盈亏比 2:1 的策略（期望为正）：

- 每次满仓梭哈：连亏 4 次直接腰斩，心理崩溃割在底部
- 每次投 20%：连亏 4 次回撤约 -20%，策略继续运行，等来大盈利

**同样的策略，唯一区别是仓位，结局天壤之别。** 新手三大死法：
满仓梭哈、亏损加仓摊平、盈利拿不住亏损扛到底 —— 全是仓位问题。

## 8.2 四种仓位法（从幼儿园到研究生）

### ① 固定金额（第一年用这个）

每笔固定 1 万，亏完为止。简单、痛感清晰、天然控回撤。
```python
from ch06_risk.position_sizing import fixed_amount
size = fixed_amount(equity=100_000, per_trade=10_000)   # 10_000
```

### ② 固定比例

每笔投入总资金的 10%~30%。账户会自动"赢了加仓输了减仓"，复利友好。
```python
size = fixed_fraction(100_000, 0.2)   # 20_000
```

### ③ 波动倒推（ATR 风险预算法）—— 专业标准做法

**先定"这笔最多亏总资金的 1%"，再用波动率倒推能买多少：**

```
允许亏损额   = 总资金 × 1%           = 1000 元
止损距离     = 2 × 日均波动幅度       = 2 × 1% = 2%
仓位市值     = 1000 / 2%             = 50000 元
```

波动大的标的自动少买，波动小的自动多买——**每个仓位的风险是均等的**。
```python
size = atr_risk(equity=100_000, risk_pct=0.01, atr_pct=0.01)   # 50_000
```
日均波动（atr_pct）哪里来：`df["close"].pct_change().std()`。
币安 BTC 约 2~4%，A 股宽基 ETF 约 0.8~1.5%。

### ④ 半凯利（理论最优打对折）

凯利公式按胜率和盈亏比算"长期复利最优"比例：`f* = W - (1-W)/R`。
但参数是估的，全凯利波动巨大，**实践永远用半凯利**：
```python
frac = kelly(win_rate=0.4, win_loss_ratio=2.0)   # 0.05 → 5%
size = 100_000 * frac
```
胜率/盈亏比哪里来：**第 5 章回测的 trade_stats**。样本 <50 笔别用凯利。

## 8.3 止损：认错的纪律

趋势策略标配 **2×ATR 移动止损** 或 **固定百分比止损**（入场价 -5%~-8%）：

- 买入时**同时**写下止损价（心理账户，或写在持仓表里）
- 触发无条件执行——你只控制仓位，不控制行情
- 止损后策略翻多想再进？按规则再进

**止损必须和策略一起回测**（否则你实盘跑的不是你回测过的东西）。本项目引擎已内置：

```bash
python code/ch04_backtest/run_dual_ma.py --stop-loss 0.05   # 5% 固定止损
```

语义：当日最低价击穿持仓均价×(1-5%) → 次日开盘卖出（无前视）；止损优先于同一天的
普通信号；止损后要等到一次全新的金叉跳变才重新入场。把加与不加止损的两份回测
对比一下，你会亲眼看到止损的代价与价值。

本项目监测机器人（第 10 章）内置了"从高点回撤提醒"，可当止损闹钟用。

## 8.4 账户级风控：三条铁律

1. **总仓位上限**：趋势策略闲置期持币不代表没风险，单一市场 ≤ 总资金 80%。
2. **单笔风险上限**：任何一笔交易的"最大亏损"（仓位 × 止损距离）≤ 总资金 1~2%。
3. **月度熔断**：单月回撤 > 10% → 停止交易一周，复盘后再开。机器人也会犯傻，
   熔断是给"人和机器都失控"时准备的最后一道闸。

## 8.5 心理账户：把回测回撤换算成"你的钱"

回测里 -41% 是一个数字，实盘是：

```
100 万账户 → 最深时账面剩 59 万 → 且你不知道会不会继续跌
```

**实盘前练习**：拿第 4 章的回撤图，在纸上写下"如果这一切发生在真钱上，
我在回撤 10%/20%/30% 时分别会做什么"。答案不体面没关系，**诚实比勇敢重要**，
然后按你的真实承受力反推仓位（承受不了就把 8.2 的比例砍半）。

## 8.6 复利与提现纪律

- 盈利部分定期提现（例如每翻一倍提回本金）——市场永远在，本金安全第一。
- 加仓速度慢于盈利速度：翻倍后仓位比例自动减半（固定金额法天然如此）。
- **永远不用生活必需资金、不借钱、不上杠杆**进入你还没在测试网/模拟盘验证过的策略。

4. 思考题：为什么"亏损加仓摊平成本"在趋势策略里是毒药？（提示：趋势策略的死叉意味着什么）

## 常见的坑

- 把"ATR 仓位法"用在负期望策略上——仓位管理只能让你死得慢，**不能把亏钱的策略变成赚钱的**。
- 止损位形同虚设：到了又改"再等等"——那就别设。
- 凯利用全仓版本。
