# 第 12 章 参考答案

## 题 1：任务计划 / cron，连续 3 天收到推送
- Windows：任务计划程序 → 创建基本任务 → 触发器"每天 8:30" → 操作 `python code/ch08_monitor/monitor_astock.py --once`（用绝对路径，见 12.2）。
- Linux：`crontab -e` 加 `30 8 * * 1-5 cd /path/to/量化 && .venv/bin/python code/ch08_monitor/monitor_astock.py --once`。
**验收**：连续 3 个工作日自动收到晨报推送。

## 题 2：故障演练（记录恢复时间）
对照 12.6 的四项演练，记录每项"发现→恢复"的耗时：
1. 断网重启（机器人/任务是否自动恢复）
2. 删掉缓存 CSV（是否自动重下/降级）
3. 改错 API Key（错误分诊是否停机+推送，而不是静默死循环）
4. 磁盘写满（日志是否可控）

**产出**：一张"故障 → 现象 → 恢复步骤 → 耗时"的表。这张表就是你上真钱前的底气。

## 题 3：心跳晨报
```bash
# cron 每天 20:00 跑一次强制晨报，兼当"我还活着"信号
0 20 * * * cd /path/to/量化 && .venv/bin/python code/ch08_monitor/monitor_astock.py --once --force
```
与第 9 章机器人的每日心跳互补：机器人发的是"币安机器活着"，这里是"A 股监测活着"。

## 题 4：Docker 完整部署
```bash
docker compose -f scripts/docker-compose.yml up -d
docker compose logs -f
```
**要点**：先在本机跑通再上 VPS；容器内时区设为 `Asia/Shanghai`；`.env` 通过 volume 挂载、不要打进镜像。
