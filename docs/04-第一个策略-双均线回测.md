# 第 4 章 · 第一个策略：双均线回测（从零理解回测引擎）

> **学习目标**：彻底理解一个策略如何从想法变成回测报告；亲手跑通并逐行读懂回测引擎。
> **配套代码**：`code/ch04_backtest/engine.py`（引擎）、`run_dual_ma.py`（策略+入口）
> **耗时**：1~2 天

## 4.1 策略思想：趋势存在惯性

**双均线择时（Dual Moving Average Crossover）**：

- MA20 = 最近 20 天收盘价的平均（短期趋势 / 快线）
- MA60 = 最近 60 天收盘价的平均（长期趋势 / 慢线）
- **金叉**（MA20 上穿 MA60）：短期动能转强 → 满仓
- **死叉**（MA20 下穿 MA60）：动能衰竭 → 空仓

它当然不完美（震荡市会被来回打脸），但它**逻辑透明、参数少、跨市场通用**，
是理解"信号→仓位→成交→净值"这条流水线的最佳教具。你以后写的任何复杂策略，
流水线都是这一条。

## 4.2 策略函数只有 8 行

```python
def dual_ma_weights(df, fast=20, slow=60):
    ma_fast = df["close"].rolling(fast).mean()   # 每天的快线值
    ma_slow = df["close"].rolling(slow).mean()   # 每天的慢线值
    weights = pd.Series(float("nan"), index=df.index)
    weights[(ma_fast > ma_slow) & ma_slow.notna()] = 1.0   # 多头状态：满仓
    weights[(ma_fast <= ma_slow) & ma_slow.notna()] = 0.0  # 空头状态：空仓
    return weights
```

关键设计：**策略只输出"目标仓位"（0~1），不管怎么成交**。
信号与执行分离——这样换策略只换这个函数，引擎完全复用。

### 4.2.1 拆开这 8 行：pandas 向量化、布尔索引与 NaN（零基础最大的坎）

第 1 章你学的是"对单个数字做判断"。但策略要同时判断 2106 根 K 线——难道写 2106 次 if？
不，pandas 用**向量化**：一个表达式同时作用在整列数据上。看这行：

```python
weights[(ma_fast > ma_slow) & ma_slow.notna()] = 1.0
```

从左到右拆成四步：

1. `ma_fast > ma_slow`：不是"两个数字比大小"，而是"两个**列**比大小"——得到一列 `True/False`（每天一个）。
2. `ma_slow.notna()`：`notna()` = not NaN，判断"慢线这一天有没有值"。慢线要 60 天数据才出第一个值，前 59 天是 `NaN`（Not a Number，缺失值）。
3. `&`：这里是 pandas 的"**逐元素与**"，不是第 1 章的 `and`——我们要的是"每一天"同时满足两个条件，而不是"整个 Series 是不是 True"。
4. `weights[条件] = 1.0`：**布尔索引**——只把"条件为 True"的那些天设成 1.0，其余保持不动。

**为什么要 `& ma_slow.notna()` 这一坨？** 因为 `NaN > 任何数` 的结果还是 `NaN`（不是 True 也不是 False）。不去掉 NaN，前 59 天就会被假判断污染。`notna()` 把"数据还没就绪"的天明确排除掉。

**NaN 在量化里的约定**（第 4~9 章反复用到）：
- NaN = "数据不足，维持现状不动"，**不是"清仓"**。
- 策略返回 NaN，引擎和实盘机器人都会"跳过这一天、保持原仓位"，绝不反向操作。

> 如果你卡在这里了，别慌——这是全教程**唯一一个真正的陡坡**。把上面四步抄一遍，
> 再自己敲一个 `df[df["close"] > 100]` 感受"布尔索引"，就翻过去了。

## 4.3 回测引擎的骨架（读懂这 30 行伪代码就懂了引擎）

```
现金 = 100000; 持股 = 0
对每一根K线:
    1. 如果昨天收盘有信号没执行 → 以今天开盘价成交（无未来函数！）
    2. 记录净值 = 现金 + 持股 × 今收
    3. 用今收计算新信号 → 排队等明天开盘执行
成交时:
    买入价 = 信号价 × (1 + 滑点)   卖出价 = 信号价 × (1 - 滑点)
    手续费 = 成交额 × 费率
    调仓金额 < 净值×0.5% → 忽略（防止碎单）
```

`engine.py` 的完整实现加了三类保护，都是实盘会用到的细节：

1. **`min_trade_pct`**：净值 10 万时 500 块以下的调仓直接跳过；
2. **现金不能买穿**：`notional = min(delta, cash/(1+费率))`；
3. **只能卖持仓**（做多策略，不做空）。

### 4.3.1 真实引擎的核心循环（逐行）

`engine.py` 里最核心的是这个 for 循环（已精简到骨架，完整版还含止损/最低佣金/现金护栏，第 8 章讲）：

```python
for i, (when, row) in enumerate(df.iterrows()):
    # 1) 执行昨天排队的信号（用今天的开盘价成交）—— 杜绝未来函数
    if i > 0 and pending_weight is not None:
        _execute(pending_weight, float(row["open"]), when)
        pending_weight = None
    # 2) 用今天的收盘价记录账户净值
    equity_values.append(cash + shares * float(row["close"]))
    # 3) 用今天的收盘价算出新信号，排队等明天开盘执行
    w = weights.iloc[i]
    pending_weight = None if pd.isna(w) else float(w)
```

逐行理解：

- `df.iterrows()`：逐根 K 线地"走过"整个历史，每轮拿到 `when`（日期）和 `row`（当天 OHLC）。
- **第 1 步先执行昨天排队的信号**，用的是"今天的开盘价"——昨天收盘时你还不知道今天开盘价，今天开盘了才能按它成交。这就是"次日开盘成交"，杜绝了未来函数。
- **第 2 步**用今天的收盘价记账：净值 = 现金 + 持股数 × 收盘价。
- **第 3 步**用今天的收盘价算新信号，但它只**排队**，要等明天的开盘价才真正成交。

> 这三步的**顺序**（先成交昨天的、再记账、再算明天的）是整个回测引擎的灵魂。
> 顺序错了就是未来函数。你读懂了它，就再也不会被"回测漂亮、实盘打脸"的框架骗到。

## 4.5 读懂你的第一份"成绩单"

在 510300（2018~2026，含 2021~2024 大熊市）上，本策略的真实结果大致是
**（截至 2026-09 的快照，数字会随行情漂移；以你重跑的输出为准）**：

| 指标 | 数值 | 怎么理解 |
|------|------|---------|
| 总收益率 | ≈ -2% | 8 年白忙，但也没亏 |
| 最大回撤 | ≈ -41% | 2021 峰值到 2025 谷底，拿住极难 |
| 交易次数 | 23 | 8 年 23 次，频率健康 |
| 胜率 | 30% | 10 次只赢 3 次！ |
| 单笔盈利均值 | +9.3% vs 亏损 -3.8% | 盈亏比 2.4:1，趋势策略的典型画像 |

**对照买入持有（+35%）它跑输了**——但注意 2022~2024 熊市里它大部分时间空仓，
回撤 41% vs 指数近腰斩。这就是趋势策略的本质：**牛市跟得上、熊市躲得开、震荡市磨死人**。
（同参数在 BTC 上 3 年约 +52%——截至 2026-09 快照——因为币圈趋势性远强于 A 股宽基。）

## 4.6 关键实验：亲手制造"未来函数"，看它多能骗人

```bash
# 诚实模式（默认）：收盘出信号，次日开盘成交
python code/ch04_backtest/run_dual_ma.py --execute-on next_open
# 作弊模式：当天收盘信号当天收盘成交（实盘做不到！）
python code/ch04_backtest/run_dual_ma.py --execute-on close
```

对比两张结果：作弊模式的收益率会"凭空"更好——因为它偷看了收盘价。
这就是第 2 章说的前视偏差。**市面上无数吹上天的回测就是这么造出来的。**
你现在已经拥有识别它的免疫力。

## 4.8 引擎没做什么（诚实清单）

- ✘ 不支持做空、杠杆、期权
- ✘ 不模拟涨跌停（A 股极端日可能买不进）、停牌
- ✘ 不模拟部分成交/排队（市价单近似全成）
- ✘ A 股 T+1 未建模（当天买次日才能卖——日线策略天然满足）

这些近似对**日线级、ETF/主流币、低频**策略影响很小；做分钟级或个股高频前，你需要
backtrader/vnpy 这类专业框架（第 13 章导读）。**知道工具的边界，比会用工具更重要。**

## 常见的坑

- 信号列全是 NaN：数据不够慢线窗口（60 日均线需要 ≥60 行数据）。
- 回测起点不同结果不可比：任何对比必须**同区间、同成本、同成交模式**。
- 用分红不复权数据做回测 → 满屏假信号（回看第 2.3 节）。
