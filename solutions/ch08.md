# 第 8 章 参考答案

## 题 1：四种仓位法对比（10 万、BTC 波动 2.5%、风险 1%）
```bash
python code/ch06_risk/position_sizing.py --method fixed_amount --equity 100000 --per-trade 10000
python code/ch06_risk/position_sizing.py --method fixed_fraction --equity 100000 --fraction 0.2
python code/ch06_risk/position_sizing.py --method atr_risk --equity 100000 --risk-pct 1 --atr 0.025
```
- 固定金额：1 万
- 固定比例 20%：2 万
- ATR 波动倒推（单笔亏 1% = 1000 元，止损距离 2×2.5%=5%）：1000 / 5% = **2 万**

**关键差异**：固定金额和固定比例只看"你愿意投多少"，ATR 法则反过来看"你最多亏多少"再倒推仓位——后者才是专业做法（先定风险，再定仓位）。

## 题 2：半凯利
```bash
python code/ch06_risk/position_sizing.py --method kelly --equity 100000 --win-rate 0.30 --win-loss-ratio 2.4
```
用第 4 章双均线的真实参数（胜率 30%、盈亏比 2.4）代入：`f = 0.30 - 0.70/2.4 = 0.008`，半凯利 = 0.4%。**这就是为什么凯利要用"半"甚至"四分之一"**——胜率和盈亏比都是估计值，误差大，全仓凯利等于自杀。

## 题 3：个人风控章程（模板）
```
单笔风险：总资金的 1%
最大总仓位：50%（永不满仓）
止损规则：持仓均价亏 5% 无条件离场
月度熔断：单月亏 5% 停手复盘
```
**没有标准答案，但有标准底线**：单笔风险 ≤ 2%、止损必设、熔断必写。写下来贴屏幕边，比任何"完美参数"都值钱。

## 题 4：思考题"亏损加仓摊平成本"为什么是毒药
答案：趋势策略的**死叉 = 趋势终结信号**。价格一路下跌时，你的均线策略早就该空仓了，"亏损加仓"等于在趋势已经转空时**逆势接飞刀**——摊平成本摊到的是更大的亏损。

更深一层：加仓摊平是"用新钱去救旧错"，它破坏了仓位管理的前提（每次决策独立、风险可控）。**趋势策略赚的是"顺势"的钱，加仓摊平是"逆势"的行为，方向完全相反**。正解是认错止损（第 8.3 节），而不是加仓。
