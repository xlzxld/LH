# 第 10 章 参考答案

## 题 1：开通推送渠道
在 `.env` 里填任一渠道（Server酱 / PushPlus / 企业微信）的 key，跑：
```bash
python code/ch08_monitor/monitor_astock.py --once --force
```
收到测试推送即成功。若收不到，按常见坑排查：key 是否复制全、Server酱免费额度（5 条/天）、代理干扰。

## 题 2：改 WATCHLIST
`.env` 里 `WATCHLIST` 改成你真正盯的 3~5 个标的（格式 `etf:510300,stock:600519,...`），或临时试单个标的：
```bash
python code/ch08_monitor/monitor_astock.py --once --force --codes 'etf:510300'
```

## 题 3：改 MA 参数与回测一致
把 `.env` 里的 `MA_FAST/MA_SLOW` 改成你第 7 章验证过最稳健的参数。**关键原则：监测机器人的信号必须和你回测用的参数完全一致**，否则你"回测验证的是 A、实盘跑的是 B"，等于白验证。

## 题 4：加"放量"规则
在 `monitor_astock.py` 的 `check_signals()` 里加一条：
```python
# 放量：当日成交量 > 5 日均量 × 2
vol_ma5 = df["volume"].rolling(5).mean().iloc[-1]
vol_today = df["volume"].iloc[-1]
if vol_today > vol_ma5 * 2:
    signals.append(("放量", f"成交量 {vol_today/vol_ma5:.1f} 倍于 5 日均量"))
```
要点：**任何新规则都要先回测验证再上监测**，否则你只是给机器人加了一条"噪声"。
