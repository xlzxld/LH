# 第 5 章 · 绩效评估与回测进阶：别被一张漂亮表骗了

> **学习目标**：手算每个指标；掌握参数敏感性、样本外验证两件防过拟合武器。
> **配套代码**：`code/ch05_metrics/performance.py`
> **耗时**：1~2 天

## 5.1 指标逐个手算（用 10 个数字的迷你净值）

净值序列（元）：`100 → 110 → 99 → 121 → 110`

**日收益率** = 今天/昨天 - 1：
`+10%, -10%, +22.2%, -9.1%`

**总收益率** = 110/100 - 1 = **+10%**。（注意：+10% 和 -10% 不对称，-50% 要 +100% 才回本）

**年化 CAGR**：`期初^（1/年数）- 1`。这 4 个周期按日线≈4/252 年，
CAGR = 1.1^(252/4) - 1 ≈ **+40,000%**——看到没有，短线神化就是这么来的（4 天赚 10%
年化就是荒谬的四万倍），
区间够长年化才有意义，**少于 1 年的年化一律别信**。

**波动率** = 日收益标准差 × √252（时间放大 law: 独立随机变量方差相加）。

**夏普比率** = (年化收益 - 无风险利率) / 年化波动。设无风险 2%：
超额年化会是一个天文数字（这正说明：少于 1 年的年化/夏普没有意义），波动算出来很大，夏普其实一般——
**夏普惩罚的是"上蹿下跳地赚"**。两条净值曲线收益相同，夏普高的那条拿得住。

**最大回撤**：历史最高 121，谷底 110，回撤 = 110/121-1 = **-9.1%**。
`performance.max_drawdown` 用 `cummax()` 三行实现，`compute_stats` 还返回了
峰谷日期——**知道你的钱最深套在哪一天、套多久，是心理建设的一部分**。

**索提诺**：只惩罚下跌波动（涨得猛不算风险）。**卡玛** = 年化/|最大回撤|，
衡量"每挨一记重拳换来多少年化"。

`performance.py` 的 `compute_stats()` 把上面全部一次算齐，`print_stats()` 打成对齐表格；
**建议你拿迷你例子手算一遍再去看代码**，公式就再也不用背了。

## 5.2 胜率 vs 盈亏比：策略的两种人格

`trade_stats()` 把成交流水配对成"一买一卖"结算：

- **趋势策略**：胜率 30~40% + 盈亏比 2~3 → 靠"赚大亏小"活
- **回归策略**：胜率 60~70% + 盈亏比 0.5 → 靠"赢多输少"活

期望收益 = 胜率×平均盈利 - (1-胜率)×平均亏损。**只要这个数 > 成本，策略就有戏。**
所以下次看到"我胜率 90%"先问盈亏比——胜率 90% 盈亏比 0.05 的策略，一次黑天鹅全吐回去。

## 5.3 净值图怎么读（三栏分析法）

`plot_equity()` 生成的图：

1. **上栏策略 vs 基准**：不是看谁终点高，而是看**路径**——策略是否用更平缓的路径到达？
2. **下栏回撤面积**：找三样东西：最深的一次（MDD）、最长的一次（回撤持续时间）、
   回撤修复速度。**设想这是你的账户**，问自己三个问题：
   能忍受吗？会在哪一跳割肉？割肉后策略马上反弹怎么办？

## 5.4 防过拟合武器一：参数敏感性热力图

思想：**真规律不会只住在一个参数点上。**

```python
# 网格扫描：快线 5~40 步长5 × 慢线 40~120 步长10
results = {}
for fast in range(5, 45, 5):
    for slow in range(40, 130, 10):
        if fast >= slow:
            continue
        w = dual_ma_weights(df, fast, slow)
        r = run_backtest(df, w, with_benchmark=False)
        results[(fast, slow)] = r.stats["年化收益率(CAGR)"]

import pandas as pd
grid = pd.Series(results).unstack()
print((grid * 100).round(1))     # 年化% 热力表
```

判读：
- **整片区域都是正的、相邻点相近** → 规律稳健 ✔
- **孤峰**（一个点 50%，邻居全负）→ 数据噪音，实盘必死 ✘

再加两道保险：把样本切成 2018-2022 / 2022-2026 两段分别跑，
两段同参数都赚钱才算数（时间稳健性）；换标的（510300 → BTC）还成立吗（空间稳健性）。

## 5.5 防过拟合武器二：样本外验证（Walk-Forward 思想）

```
训练段 2018~2022：调参数，选出最优 fast=20, slow=60
测试段 2023~2026：参数锁死，只跑一遍看结果
```

**测试段的成绩才是策略的真实成绩预估。** 测试段显著变差 → 训练段的好结果是过拟合。
科研式的正确姿势：滚动前进（每年重新训练、下一年验证），第 13 章的进阶书单有完整方法论。

## 5.6 基准与超额：你在赚"谁"的钱

和谁比决定结论：

| 对照 | 策略 +8% 年化的含义 |
|------|--------------------|
| 沪深300 同期 +5% | 超额 +3%，有点东西 |
| 沪深300 同期 +15% | 跑输，不如躺平买 ETF |
| 余额宝 2% | 赢了，但承担了权益波动 |

所以引擎自动生成"买入持有"基准曲线（`with_benchmark=True`）。
**永远把"策略 vs 躺平"放在"策略今年赚了多少"前面看。**

## 5.7 回测报告的诚实清单（发布/自审模板)

一个合格回测必须交代：

1. 数据区间与来源、复权方式
2. 成本假设（费率/滑点数字）
3. 成交模式（next_open / close）
4. 参数及选择依据（是否在测试段选出）
5. 完整指标表（含 MDD/夏普），不许只晒收益
6. 交易次数（<30 次的结果没有统计意义）

本项目 `run_dual_ma.py` 的输出覆盖第 1/2/3/5/6 项；第 4 项（参数依据）要靠你自觉。

## 常见的坑

- 只用一段大牛市回测 → 所有趋势参数都好看（牛市里均线买入就对）。
- `pct_change()` 第一行是 NaN 忘了 drop，夏普算出 nan。
- 用"测试段成绩"再回去调参数 → 测试段被污染，等于没有测试段。
