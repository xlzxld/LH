## 题 2：check(df) 函数
```python
def check(df):
    assert df.index.is_monotonic_increasing, "时间未升序"
    assert not df.index.has_duplicates, "存在重复日期"
    assert (df["close"] > 0).all(), "存在非正收盘价"
    gap = df.index.to_series().diff().dt.days.max()
    print(f"行数 {len(df)}，区间 {df.index[0].date()}~{df.index[-1].date()}，最大间隔 {gap} 天")
    return True
```

## 题 3：单日涨跌幅最大的 5 天
```python
import pandas as pd
df = pd.read_csv("data/astock_510300.csv", index_col=0, parse_dates=True)
ret = df["close"].pct_change()
print(ret.nlargest(5))    # 涨幅最大的 5 天
print(ret.nsmallest(5))   # 跌幅最大的 5 天
```
拿着日期去搜新闻，你会发现大涨/大跌日几乎都对应着"重大政策/黑天鹅"（比如 2024-09-24 政策组合拳单日大涨）。**这就是"行情由事件驱动"的直观证据**。

## 题 4：分段拉取 3 年 BTC 4h 线
```python
import ccxt
ex = ccxt.binance()   # 或 make_exchange(with_keys=False)
all_rows = []
since = ex.parse8601("2023-01-01T00:00:00Z")
while since < ex.parse8601("2026-01-01T00:00:00Z"):
    rows = ex.fetch_ohlcv("BTC/USDT", timeframe="4h", since=since, limit=1000)
    if not rows:
        break
    all_rows += rows
    since = rows[-1][0] + 1   # 从最后一根之后继续
print(f"共 {len(all_rows)} 根")
```
要点：`since` 参数指定起始时间戳，每批最多 1000 根，取完把 `since` 推到"最后一批之后"继续拉。这就是"分页拉数据"的通用套路。
