## 11.2 聚宽策略的骨架（所有平台通用思想）

```python
def initialize(context):
    """开局跑一次：基准、费率、调度"""
    set_benchmark("000300.XSHG")          # 基准=沪深300指数
    set_option("use_real_price", True)    # 真实价格模式
    set_order_cost(OrderCost(...), type="fund")   # 手续费建模
    run_daily(run_strategy, time="9:35")  # 每天9:35执行主体逻辑

def run_strategy(context):
    """每天：算信号 → 下单"""
    bars = get_bars("510300.XSHG", count=61, unit="1d", fields=["close"], ...)
    ma_fast = bars["close"][-20:].mean()
    ma_slow = bars["close"][-60:].mean()
    if ma_fast > ma_slow:
        order_target_value("510300.XSHG", context.portfolio.total_value * 0.95)
    else:
        order_target("510300.XSHG", 0)    # 清仓

def handle_data(context, data):
    pass   # 平台要求的固定入口，用 run_daily 调度后留空
```

三个平台思维的收获（换 BigQuant/果仁/QuantConnect 都一样）：

1. **平台提供"上下文对象"**（context.portfolio 总资产/持仓；data 当日数据），不用自己记账
2. **下单是"目标仓位制"**：`order_target_value(标的, 目标市值)` 平台自动算差价单，
   等价于本项目引擎的 `target_weights` 思想——你已经在第 4 章见过它的底层
3. **回测/模拟盘同一份代码**：点一下开关，平台每天用实时行情替你跑

## 11.5 平台 vs 本地：怎么选

| | 聚宽等平台 | 本项目本地路线 |
|---|-----------|--------------|
| 环境成本 | 零 | venv + 依赖 |
| 数据 | 全（含财务/基本面） | 行情为主（可自行扩展） |
| 自由度 | 框架规定动作 | 任意黑科技（自定义风控/订单逻辑/多所对冲） |
| A股自动下单 | 模拟盘/实盘对接有门槛 | 本项目采用"推送+手动" |
| 加密货币 | ✘ | ✔（第 9 章） |
| 长期 7×24 | 平台托管 | 自己部署（第 12 章） |

**推荐组合拳**：想法在平台快速验证 → 定稿后移植到本地引擎复核 →
实盘走第 9 章（币安自动）或第 10 章（A 股推送手动）。

## 常见的坑

- 聚宽代码带交易所后缀：`.XSHG` 上海 / `.XSHE` 深圳，漏写直接报错。
- 平台默认复权/费率与本地不同：对比前先对齐口径（`set_order_cost` + 真实价格模式）。
- 回测收益巨高的小市值策略：多数含幸存者偏差/流动性幻觉，先读社区"打假"帖再兴奋。
- **100 股整手限制**：A股买入必须是 100 股（1 手）的整数倍。高价股小资金根本买不起
  1 手——比如贵州茅台 1500 元/股时 1 手就要 15 万，订单会被拒绝，报错文案是
  "开仓数量不能小于 100"。选标的前先算一笔账：**股价 × 100 是否在你的资金范围内？**
  小资金建议像本策略一样选 ETF 或低价股。
- **重复下单**：`order_value("xxx", 50000)` 是"再买 5 万"，不是"持有到 5 万"——
  每天调用一次就会每天加仓 5 万。两个解法：① 用目标仓位制 `order_target_value` /
  `order_target`（平台自动算差价单，已到位就不再动，本策略和 11.2 骨架都是这种，
  天然幂等）；② 坚持用市价单就得自己判断持仓状态，只在空仓时买、有仓时卖：
  ```python
  pos = context.portfolio.positions[sec].total_amount  # 当前持股数
  if ma_fast > ma_slow:
      if pos == 0:
          order_value(sec, context.portfolio.available_cash)  # 只在空仓时买
  else:
      if pos > 0:
          order_target(sec, 0)                                # 只在有仓时清
  ```
