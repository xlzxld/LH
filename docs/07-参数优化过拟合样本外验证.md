# 第 7 章 · 参数优化、过拟合与样本外验证

> **学习目标**：学完本章，你能判断"这个回测结果靠不靠谱"，并且知道**哪些策略不能上实盘**。
> **前置**：第 6 章（会造策略）。**配套代码**：`code/research/param_scan.py`、`code/research/walkforward.py`。
> **耗时**：约 2~3 小时。

---

## 7.1 参数的诱惑与陷阱

双均线策略里的 `fast` 和 `slow` 就是**参数**。参数的诱惑在于：**每调一次，回测都可能好看一点点**。

```bash
python code/ch04_backtest/run_dual_ma.py --fast 20 --slow 60   # 总收益 -1.6%（截至 2026-09 快照）
python code/ch04_backtest/run_dual_ma.py --fast 10 --slow 30   # 咦，这次好一点？
python code/ch04_backtest/run_dual_ma.py --fast 5  --slow 40   # 再试试这个……
```

调着调着，你总能找到一组"历史上赚钱"的参数。然后兴冲冲上实盘——**结果往往是亏损**。

为什么？因为你在做一件危险的事：**反复偷看答案**。历史数据是"已知答案的考卷"，你每调一次参数，就多偷看一次答案，直到背出一份满分答卷。但实盘是**新考题**，背下来的答案没用。

本章就是教你怎么**诚实地**调参和验证，避免自欺欺人。

---

## 7.2 参数网格扫描：把所有组合摊开看

与其一组一组地试，不如一次性把所有组合都跑出来，摊在桌面上看。这就是 `param_scan.py`：

```bash
python code/research/param_scan.py --astock 510300
```

它会输出一张"参数 × 总收益"的热力图（类似下面这样，数字是示意）：

```
fast\slow        40        60        80       100       120
        5      3.2%      2.1%      1.5%      0.8%      0.3%
       10      4.0%      3.8%      2.9%      2.2%      1.6%
       15      3.5%      5.1%      4.2%      3.4%      2.7%
       20      2.9%      6.3%      5.8%      4.9%      4.0%
       30      2.1%      4.8%      6.9%      6.1%      5.2%
       40      1.5%      3.9%      5.4%      7.2%      6.4%
```

**这张图比任何单一数字都诚实。** 看它的时候问自己两个问题：

1. **最优参数是"孤岛"吗？** 如果只有 `MA20x60` 好，旁边 `MA15x60`、`MA25x60` 都很差——这个"最优"极可能是运气，实盘大概率失效。
2. **是一大片区域都好，还是只有一点好？** 如果 `MA20~40 x 60~120` 这一整片都赚钱，说明策略有**真逻辑**（参数稳健）；如果只有针尖大的一点好，就是过拟合。

> **参数稳健性**是判断策略好坏的核心直觉：好策略换了邻近参数"差不多一样好"，坏策略换了参数就崩。

## 7.3 过拟合：背答案的学霸

**过拟合**（overfitting）= 把参数来回调到历史数据完美，就像背答案的学霸——一考新题就露馅。

它有个更隐蔽的数学事实叫**多重比较**：你试了 100 组参数，其中总有几组"恰好"历史表现很好，这是**纯运气**，不是策略真的行。试得越多，运气越好，越容易骗到自己。

更狠的问题是：你每调一次参数，就**消耗掉一次"偷看答案"的机会**。调到第三十次时，那张热力图已经不能证明任何东西了——因为它已经是你"对着答案改出来的"结果。

**记住这句话**：回测结果的"好看"程度，和你调参的次数成正比，和策略的真实质量**没有半毛钱关系**。

---

## 7.4 样本外验证：把数据锁起来

破解过拟合的唯一办法，是**在调参之前，先把一段数据锁起来**：

- **样本内（练习册）**：前面一大段，随便你怎么调参、研究。
- **样本外（考试卷）**：后面一小段，**锁起来不许看**，等你策略定稿后再打开验证。

如果样本内漂亮、样本外一塌糊涂 → 你就是背答案的学霸，**这个策略不能上实盘**。

配套脚本 `walkforward.py` 帮你做这件事：

```bash
python code/research/walkforward.py --astock 510300 --fast 20 --slow 60
```

输出类似：

```
[切分] 样本内 2018-01-02~2023-09-01（1379 根）
[切分] 样本外 2023-09-04~2026-09-04（727 根）

样本内（练习册）: 总收益  12.34% | 年化  2.10% | 夏普  0.42 | 回撤 -18.2% | 交易 45 次
样本外（考试卷）: 总收益   3.10% | 年化  1.02% | 夏普  0.19 | 回撤 -15.6% | 交易 18 次

[判定]
  ✅ 样本外仍为正收益，策略通过了第一道关。
```

**判定逻辑就三条**：
1. 样本外交易次数 < 5 → 没统计意义，多留几年数据再验；
2. 样本外亏损 → 过拟合，不能上实盘；
3. 样本内外收益差距 > 20 个百分点 → 策略在"过期"，警惕。

> ⚠️ **样本外只能看一次。** 看完再回去改参数，考试卷就变成了练习册，验证就失效了。这是纪律，不是建议。

## 7.5 滚动验证（walk-forward）：更严谨的做法

7.4 只切了一刀，样本外只有一个"样本"。更严谨的做法是**滚动前进**：把数据切成多段，每段都用"前一段调参、后一段验证"，滚动往前推。这样你能得到**很多次**样本外表现，判断更可靠。

这个概念（也叫 walk-forward analysis）是专业量化的标配。本教程不展开实现，你理解原理即可；想深入，第 13 章的进阶书单里 `backtrader`、`vn.py` 都内置了滚动回测。

## 7.6 上实盘前清单（硬门槛）

到这里，你具备了"造策略 + 验证策略"的完整能力。第 9~11 章的实盘（币安 / A股 / 聚宽）会要求你**先把这一关过了**。把下面这份清单抄下来，贴在屏幕上：

```
【策略上实盘前，逐条打勾】
□ 1. 有样本外记录：walkforward.py 样本外为正，且不是"孤岛参数"
□ 2. 交易次数足够：样本外 ≥ 5 笔（越多越可信）
□ 3. 最大回撤可承受：回撤 30% 你敢不敢硬扛？扛不住就降仓位（第 8 章）
□ 4. 逻辑可解释：能用一句话说清"它靠什么赚钱"（趋势？均值回归？）
□ 5. 参数稳健：邻近参数"差不多一样好"，不是针尖上的最优
□ 6. 没有未来函数：信号只用"当时已知"的信息
```

**任何一条不满足，都别急着上实盘。** 缺的不是钱，是纪律。

## 7.7 动手环节

1. **跑参数扫描**：`python code/research/param_scan.py --astock 510300`，找到最优参数。它是"孤岛"还是"一整片好"？
2. **跑样本外验证**：`python code/research/walkforward.py --astock 510300 --fast 20 --slow 60`。样本外是正是负？你的策略能上实盘吗？
3. **换个标的再验**：把 `--astock` 换成 `512100`（中证1000ETF），重复第 2 题。同一组参数在两个标的上都成立吗？
4. **警惕测试**：把 `--fast 5 --slow 40` 这种"极端参数"跑一遍 walkforward，观察样本内外的反差，体会什么是过拟合。
5. **（进阶）**：用第 6 章你自制的策略（比如 RSI 均值回归），替换 `walkforward.py` 里的 `dual_ma_weights`，做一次完整的样本外验证。

## 7.8 常见的坑

| 坑 | 说明 |
|----|------|
| 反复用样本外改参数 | 看一次考卷改一次答案，改到第三回考卷就变练习册了 |
| 只看年化不看回撤 | 年化 30% 但曾腰斩的曲线，往往不如年化 15%、回撤 8% 的曲线 |
| 把"运气好"当"策略好" | 交易次数太少（<5）时，正收益可能就是运气，没统计意义 |
| 忽略成本 | 一年 50 次来回、每次 0.3% 成本就是 15%。回测必须扣手续费+滑点（本引擎已默认扣） |
| 用"最新"数据当样本外 | 样本外必须是**调参时没用过**的时间段，越"新"越好（贴近未来） |
