## 题 1：手算夏普与最大回撤
用 5.1 的迷你净值 `100 → 110 → 99 → 121 → 110` 手算：

- **最大回撤 = -10%**：两段下跌里取更深的一段——第 2 天 110 → 第 3 天 99（-10%），
  深于第 4 天 121 → 第 5 天 110 的 -9.1%。**不是最后一段，更不是期初到期末**。
- **夏普 ≈ 3.3**：日收益 `+10%, -10%, +22.2%, -9.1%`，均值 3.28%、标准差 15.6%，
  代入 (3.28%×252 − 2%) / (15.6%×√252) ≈ 3.3。这个数字本身**毫无意义**——
  4 个交易日硬年化就是胡闹，题目考的是"公式会算、结论别信"。

脚本对答案：
```python
import pandas as pd
from ch05_metrics.performance import compute_stats, max_drawdown
eq = pd.Series([100.0, 110.0, 99.0, 121.0, 110.0],
               index=pd.date_range("2024-01-01", periods=5))
print(compute_stats(eq))    # 总收益率 +10%、最大回撤 -0.1、夏普 ≈ 3.33
print(max_drawdown(eq))     # (-0.1, 峰值日 第2天, 谷底日 第3天)
```
**核对要点**：
- 最大回撤 = 净值从"历史最高点"跌到"随后最低点"的最大跌幅，不是"期初到期末"的跌幅。
- 夏普 =（年化收益 − 无风险利率）/ 年化波动率，波动率大则夏普被压低——所以"高收益但大起大落"的夏普可能不如"稳健中等收益"。

## 题 2：参数网格的"孤峰" vs "高原"
直接跑第 7 章脚本（第 5 章的参数网格已经工程化成 `param_scan.py`）：
```bash
python code/research/param_scan.py --astock 510300
```
- **孤峰**：只有某一格特别亮、四周都很差 → 过拟合，参数是"背答案"背出来的。
- **高原**：一大片区域都稳定为正 → 策略有真逻辑，参数稳健。
看真实输出里 `MA30x60=23.7%` 但 `MA20x60=-1.6%`、`MA30x80=0.3%`——这就是典型的孤峰，警示意义十足。

## 题 4：BTC vs 510300，趋势策略适合哪个市场
给三条证据支撑你的结论（以真实数据为准）：
1. **趋势持续性**：BTC 的日线趋势段更长（用 `--crypto BTC/USDT` 看净值曲线陡峭段）。
2. **回撤避震价值**：A 股熊市里策略空仓躲过的回撤 vs 震荡市被打脸的次数。
3. **夏普/卡玛**：同参数下 BTC 的夏普和卡玛（收益/回撤）通常高于宽基。

**结论方向**：趋势跟踪天生适合"趋势性强、单边行情多"的市场（BTC），在"长期横盘震荡"的市场（部分宽基）会被成本磨死。这正是"策略和市场要匹配"的第一课。
