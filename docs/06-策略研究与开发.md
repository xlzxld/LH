# 第 6 章 · 策略研究与开发：从"抄策略"到"造策略"

> **学习目标**：学完本章，你能把一个模糊的想法（"我觉得最近涨的东西会继续涨"）变成一段**可回测、可解释**的代码。
> **前置**：第 3~5 章（会跑回测、看得懂绩效表）。**配套代码**：`code/research/signals.py`。
> **耗时**：约 3~5 小时。

---

## 6.1 为什么必须学会造策略

第 4 章你跑通了双均线。但你"造"它了吗？没有——你只是跑通了**别人写好的**策略。第 9、10 章实盘反复叮嘱你"装进**你自己验证过的**策略"，但整个教程到这里为止，从没人教你怎么造。这是零基础教程最普遍、也最致命的断层：**教你用工具，不教你造内容**。

本章补上这个断层。造策略其实是一条流水线，一共七步（业界叫"研究流程"）：

```
产生想法 → 提出假设 → 准备数据 → 构造因子 → 单因子检验 → 组合成策略 → 回测
```

前 6 步是本章的内容，第 7 步"回测"你已经会了（第 4 章）。学完这一章，你就从"会用策略的人"变成"会造策略的人"。

---

## 6.2 想法从哪来：三个来源

策略的起点永远是一个**想法**。它通常来自三个地方：

1. **日常观察**：你注意到的市场现象。比如"每次大跌后，过一阵子都会反弹一点"。
2. **公开研究**：别人论证过的逻辑，你分析它**现在是否还成立**。比如海龟交易、动量效应，都是几十年前就被论文论证过、今天仍被广泛使用的经典逻辑。
3. **市场异常**：价格行为里的规律。比如"节假日前后成交量异常"。

**最常见的坑**：把"事后看到的结果"当成想法。

> ❌ "我想找出这只股票**涨之前**长什么样" —— 这不是想法，是**看着答案找题目**。等你找到时，你已经偷看了未来。
> ✅ "过去一段时间涨得多的，接下来会不会继续涨？" —— 这才是可检验的想法。

---

## 6.3 把想法写成"可证伪的假设"

想法是模糊的，无法检验。下一步要把它改写成一句话，**必须能回答四个问题**：

| 要素 | 问题 | 示例 |
|------|------|------|
| 标的 | 买什么？ | 沪深300ETF（510300） |
| 触发 | 什么条件下买？ | 过去 20 天收益为正时持有 |
| 时长 | 持有多久？ | 信号转负时卖出 |
| 预期 | 预期会怎样？ | 比"一直持有"收益更高、回撤更小 |

**含糊的假设 vs 可检验的假设**：

> ❌ "买好公司长期持有能赚钱" —— 什么叫"好公司"？"长期"是多久？无法检验 = 什么都没说。
> ✅ "过去 20 天上涨的标的，未来一个月大概率继续上涨（动量效应）" —— 任何人读了都知道怎么验证。

**证伪**二字是关键：好的假设必须**存在被推翻的可能**。如果你的假设怎么说都对（"涨了是趋势、跌了是洗盘"），它就不是策略，是玄学。

---

## 6.4 构造因子：把想法变成数字

假设还是自然语言，计算机听不懂。要把它变成一个**数字**——这叫**因子**（factor）。

> **因子** = 给每个标的、在每一天打的一个分，衡量它在某个特征上强还是弱。
> 比如"过去 20 天涨了多少"就是一个因子：+5% 表示涨了 5%，-8% 表示跌了 8%。

打开 `code/research/signals.py`，里面已经写好了两个现成的因子：

```python
from research.signals import roc_factor, rsi_factor

# 动量因子：过去 20 天涨跌幅（小数）
roc = roc_factor(df, lookback=20)

# RSI 因子：0~100，>70 超买、<30 超卖
rsi = rsi_factor(df, period=14)
```

**因子 vs 策略**（先分清这两个词，你就不乱了）：
- **因子**回答"什么特征可能有用"——只给一个分数，不告诉你买不买。
- **策略**回答"买什么、什么时候买、买多少"——一整套规则，含仓位和换仓。

因子是食材，策略是菜谱。很多人一辈子在找"神奇因子"，但真正赚钱靠的是把因子用对——那是下一节的事。

---

## 6.5 单因子检验：这个数字到底有没有用

算出一个因子后，先别急着上策略。要先回答一个问题：**这个数字，真的能预测未来吗？**

最直观的检验叫**分组法**（也是"分位数检验"的简化版）：

1. 每一天，把所有标的按因子值从高到低排成队；
2. 观察**未来一段时间**（比如 20 天），高分组和低分组谁涨得多；
3. 如果长期稳定地"高分组 > 低分组"，说明因子携带了有用的信息。

我们用 RSI 做一次演示。假设想法是"超卖的会反弹"（均值回归），那么 RSI 低（超卖）的标的，未来应该涨得更多。写个小脚本验证：

```python
from ch03_data.datasource import fetch_daily_with_cache
from research.signals import rsi_factor
import pandas as pd

df = fetch_daily_with_cache("510300")
rsi = rsi_factor(df, period=14)
fwd_ret = df["close"].pct_change(20).shift(-20)  # 未来20天收益

# 按 RSI 分三档：低(超卖) / 中 / 高(超买)
q = pd.qcut(rsi, 3, labels=["低", "中", "高"])
print(fwd_ret.groupby(q).mean())   # 看三档未来20天平均收益
```

**两点必须记住**：

1. **只看平均，不看稳定**。某因子十年平均有效，但其中八年是亏的、两年暴赚——你敢用吗？好因子要"长期稳定"地有效。
2. **相关 ≠ 因果**。因子有效，不等于你找到了原因。它可能只是恰好和某个真原因同时出现。教学阶段，先接受"它有效"，深究原因留给进阶。

## 6.6 组合成策略：写一份"规则书"

因子只告诉你"哪些好"，策略还要补齐剩下的规则：**买多少、多久换一次、何时必须清仓**。

`signals.py` 里提供了一个最简的"因子→仓位"转换器，以及三个可以直接回测的完整策略：

```python
from research.signals import factor_to_weights, momentum_weights, donchian_breakout_weights, mean_reversion_weights

# 1) 最简转换：因子 > 0 就满仓，<= 0 就空仓，中间维持现状
w = factor_to_weights(roc_factor(df, 20), upper=0.0)

# 2) 动量策略：过去 N 天上涨就持有
w = momentum_weights(df, lookback=20)

# 3) 唐奇安突破（海龟）：创 20 日新高买入、跌破 10 日新低卖出
w = donchian_breakout_weights(df, entry=20, exit_=10)

# 4) 布林带均值回归：超跌买入、回到均线卖出
w = mean_reversion_weights(df, lookback=20, k=2.0)
```

这四个函数返回的都是 `target_weights`（0~1 的仓位序列），和双均线**完全同一个契约**，所以能直接喂给你第 4 章用过的回测引擎：

```python
from ch03_data.datasource import fetch_daily_with_cache
from ch04_backtest.engine import run_backtest
from ch05_metrics.performance import print_stats

df = fetch_daily_with_cache("510300")
r = run_backtest(df, momentum_weights(df, lookback=20))  # 换成你的策略
print_stats(r.stats)
```

**一份合格的规则书，要满足一个硬标准：任何人照着做，都能得到一模一样的结果。** 如果规则里混入了"看情况""感觉不好就卖"这类主观判断，它就不是策略，无法回测、无法实盘。

## 6.7 动手环节

1. **换策略回测**：用 `momentum_weights(df, lookback=20)` 回测 510300，和双均线 MA20x60 对比总收益率、最大回撤。哪个更好？为什么？
2. **写出你的第一个假设**：按 6.3 的四要素，写一个你自己的假设（不用多复杂，比如"RSI 低于 30 时买入"），然后判断它是否"可证伪"。
3. **实现你的假设**：用 `factor_to_weights` + `rsi_factor`，把你的假设变成代码，回测 510300。
4. **检验均值回归**：跑 6.5 的分组检验，看看"RSI 低"的标的未来 20 天是不是真的涨得更多。结论支持"超卖反弹"吗？
5. **（进阶）**：把 `donchian_breakout_weights` 接到回测，体会"趋势突破"和"均值回归"两种思路在回撤曲线上的区别。

## 6.8 常见的坑

| 坑 | 说明 |
|----|------|
| 未来函数 | 因子用到了"当时还不知道"的信息（如用今天收盘价和"含今天的最高价"比突破）。`signals.py` 里的唐奇安已用 `shift(1)` 规避，注意体会。 |
| 幸存者偏差 | 只用"现在还活着"的标的做研究，忘了退市的。单个 ETF 教学不受影响，但扩大到选股时必须剔除退市股。 |
| 相关≠因果 | 因子有效不代表找到原因。别急着给策略编"故事"，先用数据说话。 |
| 只看回测曲线 | 一条漂亮的曲线可能是"背答案"背出来的。下一章（第 7 章）教你用样本外验证戳破它。 |
