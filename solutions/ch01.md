## 题 2：5 日 vs 10 日均线
```python
def dual_ma(prices, fast=5, slow=10):
    ma_fast = sum(prices[-fast:]) / fast
    ma_slow = sum(prices[-slow:]) / slow
    return 1 if ma_fast > ma_slow else 0

prices = [3.9, 4.0, 4.2, 4.1, 4.5, 4.7]   # 只有 6 个数，不足 10 天
```
注意：这组 prices 只有 6 个，`prices[-10:]` 会把全部 6 个都算进去，慢线窗口"名不副实"。**结论**：均线策略需要足够多的历史数据，这正是第 4 章 NaN 概念的来源——数据不足时宁可返回"不知道"也不硬算。

## 题 3：pandas 读 CSV 统计
```python
import pandas as pd
df = pd.read_csv("data/astock_510300.csv", index_col=0, parse_dates=True)
print(f"行数 {len(df)}")                        # 约 2100
print(f"日期范围 {df.index[0].date()} ~ {df.index[-1].date()}")
print(f"收盘价均值 {df['close'].mean():.4f}")
print(f"单日最大涨幅 {df['close'].pct_change().max():.2%}")
```
`pct_change()` 是"每天相对昨天的涨跌幅"，`.max()` 取最大。预期单日最大涨幅在 5%~7% 左右（ETF 涨停是 10%，但沪深300ETF 极少触及）。
